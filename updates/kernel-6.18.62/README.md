# Update an existing OpenWrt build directory to Linux 6.18.62

This kit updates the original OpenWrt 6.18.55 source snapshot
(`0ad1348fb2a7f49c9c5941d4d8c98f88b6974e8d`) and compatible op-source
6.18.56 through 6.18.60 states. It includes a standalone Python 3.8+ script,
the source patch, and the replacement files. Applying the update requires
neither Git nor network access.

Stop any running builds. Extract the kit and pass the build root containing
`rules.mk` and `target/linux/`, such as `/home/ubuntu_2604/op`. The extracted
`build_dir/.../linux-6.18.55` directory is generated by OpenWrt and is not the
input to this script.

```sh
python3 kernel-6.18.62-update/update.py /home/ubuntu_2604/op --check
python3 kernel-6.18.62-update/update.py /home/ubuntu_2604/op
```

In an op-source checkout, the script is at `updates/kernel-6.18.62/update.py`.
If the check reports a locally modified file, review and reconcile it with
`patches/openwrt-6.18.55-to-6.18.62.patch` before applying the update. On the
original 6.18.55 snapshot, you can also use `git apply --check` and `git apply`
with that patch in place of the updater. Use the updater if you want backups,
validation of previously applied changes, or an update to op-source's device
manifest.

The updater checks every replacement against its checksum and saves the
originals with a change journal in `.kernel-update-backups/`. It preserves
`.config`, feeds, device definitions, downloads, compiled toolchains and
existing build outputs. If present, `config/device-build.json` receives the
new kernel version and hash while retaining its other settings.

To prefetch the verified kernel, add `--download` to the apply command.
Otherwise OpenWrt downloads it during kernel preparation. The pinned
[kernel.org archive](https://cdn.kernel.org/pub/linux/kernel/v6.x/linux-6.18.62.tar.xz)
SHA-256 is:

```text
490a7aedf1b355c565d3a6c05333ccccb5da82064eca46b590448a7099d7d651
```

Rebuild on a supported Linux host:

```sh
cd /home/ubuntu_2604/op
make defconfig
make target/linux/clean
make package/kernel/mac80211/clean
make target/linux/prepare -j1 V=s
make -j2 V=s
```

The two clean commands remove the selected target's kernel and mac80211 build
outputs. The new kernel and kernel modules must be compiled together. Host
and cross toolchains and the download cache are kept.

The source patch includes the accumulated Linux 6.18 and mac80211 changes
since the 6.18.55 snapshot. It removes redundant stable backports, reconciles
OpenWrt's NAND, Ethernet and platform patches with the new kernel, and keeps
the mac80211 `sockaddr_unsized` fix compatible with both sides of the stable
API reversal in 6.18.61. The p54 firmware bounds fix is included as well.

Local preflight applied all 42 kernel patch stacks and all 192 mac80211
patches with zero fuzz and no rejects. An AArch64 compile probe checked the
socket compatibility fix against the old and new kernel header layouts. The
unified patch and updater were tested against the original 6.18.55 files,
and the updater was tested against the listed earlier op-source versions.
A complete firmware build and hardware boot have not been verified.
